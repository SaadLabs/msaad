Binary Tree Visualizer

Algorithms & Data Structures • Interactive Visualizer

Interactive algorithm exploration tool focused on binary search tree data structures, tree balancing, animated node operations, and visual step-by-step traversal demonstrations built using JavaScript and C++.

Key Features & Technical Highlights

  • Dynamic Tree Construction: Real-time visual node insertion, value searching, deletion rebalancing, and depth tracking.
  • Animated Traversal Modes: Visual highlighting step-through for In-Order, Pre-Order, Post-Order, and Breadth-First Search algorithms.
  • Core Algorithm Modeling in C++: Robust memory and pointer modeling concepts ported to an interactive responsive front-end visualizer.
  • Intuitive Educational Interface: Adjustable animation speeds, tree reset capabilities, and custom dataset generation for educational clarity.
